# 联系人功能模块

## 功能概述

联系人模块是应用程序的核心组件之一，提供用户联系人的管理、显示、搜索和交互功能。该模块支持中文拼音处理、按字母分组、快速索引和搜索功能。

## 技术实现

- **状态管理**: 使用 Cubit 模式
- **数据存储**: 使用 Isar 数据库
- **UI组件**: 基于 Flutter Material 组件
- **拼音处理**: 使用 lpinyin 库

## 主要功能

1. **联系人列表显示**
   - 按拼音首字母分组
   - 支持动画效果
   - 字母索引快速导航

2. **联系人搜索**
   - 支持中文拼音搜索
   - 实时过滤结果
   - 优化的中文输入体验

3. **联系人同步**
   - 与服务器同步联系人数据
   - 本地缓存管理
   - 同步状态指示

4. **联系人互动**
   - 点击联系人进入聊天
   - 添加新联系人
   - 联系人筛选

## 开发指南

### 添加新联系人功能

要实现新的联系人相关功能，请遵循以下步骤:

1. 在 `domain/usecases` 中定义新用例
2. 在 `data/repositories` 中实现相应的仓库方法
3. 在 `presentation/cubit` 中扩展状态管理
4. 在 `presentation/pages` 或 `presentation/widgets` 中实现UI组件

### 修改现有功能

修改现有功能时，请确保:

1. 遵循文档中定义的UI和交互规范
2. 保持与现有动画和过渡效果的一致性
3. 维护中文拼音处理的准确性
4. 进行充分的测试，特别是对中文名称的处理

## 性能考虑

- 联系人列表使用懒加载和虚拟化技术
- 拼音转换结果应缓存以提高性能
- 搜索操作应优化以支持大量联系人
- 动画效果应在低端设备上保持流畅

# 联系人页面 (ContactsPage) UI 规范文档

## 1. 页面整体布局

联系人页面采用垂直布局，从上到下包含以下组件：
- 应用栏 (AppBar)
- 同步状态指示器 (可选，仅在同步时或出错时显示)
- 搜索框
- 联系人分组列表
- 右侧字母索引栏
- 悬浮添加按钮

## 2. 组件详细规范

### 2.1 应用栏 (AppBar)

- **标题**: "联系人"，居中显示，字体粗细为 FontWeight.w600
- **背景色**: 绿色 (Colors.green)
- **前景色**: 白色 (Colors.white)
- **左侧按钮**: 筛选按钮，使用 filter_list 图标
- **右侧按钮**: 刷新按钮，使用 refresh 图标
- **阴影**: 无阴影 (elevation: 0)

### 2.2 同步状态指示器

- **成功同步时**: 不显示
- **同步中**: 显示绿色进度条，白色背景
- **同步错误**: 显示红色背景的错误提示，包含错误信息和刷新按钮

### 2.3 搜索框

- **位置**: 列表顶部第一项
- **布局**: 水平布局，包含输入框和搜索按钮
- **输入框样式**:
  - 圆角边框 (20px)
  - 灰色背景 (Colors.grey[200])
  - 无边框
  - 左侧搜索图标
  - 右侧清除按钮 (仅在有输入时显示)
- **搜索按钮**:
  - 仅在有输入内容时显示
  - 绿色背景，白色文字
  - 圆角边框 (20px)
  - 文本为"搜索"
- **交互逻辑**:
  - 输入文字时不自动搜索，仅更新状态
  - 点击搜索按钮或按下回车键时执行搜索
  - 清除输入后重置搜索状态并保持焦点

### 2.4 联系人分组列表

- **分组方式**: 按拼音首字母分组
- **分组内排序**: 按拼音或名称字符串排序
- **分组标题**:
  - 灰色背景 (Colors.grey[200])
  - 宽度铺满
  - 左对齐文本，字体粗细为 FontWeight.bold，颜色为灰色
  - 内边距为水平16px，垂直8px
- **联系人列表项**:
  - 使用 ListTile 组件
  - 左侧显示头像 (CircleAvatar)
  - 标题显示联系人名称
  - 副标题显示联系人状态 (如果有)
- **动画效果**:
  - 使用 AnimatedList 为每个分组的联系人添加动画
  - 大小过渡 (SizeTransition): 从小到大展开
  - 滑动过渡 (SlideTransition): 从右侧滑入
- **滚动行为**:
  - 使用 BouncingScrollPhysics 提供反弹效果
  - 隐藏滚动条

### 2.5 右侧字母索引栏

- **位置**: 屏幕右侧，垂直居中
- **样式**:
  - 半透明灰色背景 (Colors.grey.withOpacity(0.2))
  - 圆角边框 (12px)
  - 宽度为24px
  - 垂直内边距为8px
  - 右侧外边距为8px
- **内容**:
  - 顶部显示搜索图标 (🔍)
  - 下方显示所有分组的首字母
  - 每个字母高度为20px
  - 选中状态为绿色，未选中为深灰色
- **交互逻辑**:
  - 点击字母时滚动到对应分组
  - 点击搜索图标时滚动到顶部并聚焦搜索框
  - 点击时在屏幕中央显示当前选中字母的提示
  - 搜索结果显示时隐藏索引栏

### 2.6 悬浮添加按钮 (FloatingActionButton)

- **位置**: 右下角
- **样式**:
  - 绿色背景 (Colors.green)
  - 白色加号图标 (Icons.person_add)
- **功能**: 点击时导航到添加联系人页面

## 3. 交互状态

### 3.1 正常浏览状态

- 显示所有联系人分组
- 显示右侧字母索引栏
- 搜索框在顶部

### 3.2 搜索状态

- 搜索框保持在顶部
- 下方显示搜索结果
- 隐藏右侧字母索引栏
- 无搜索结果时显示"没有找到匹配的联系人"提示

### 3.3 加载状态

- 显示居中的进度指示器
- 加载完成后显示联系人列表

### 3.4 错误状态

- 显示错误信息
- 提供重试选项

## 4. 响应式设计

- 联系人列表宽度自适应屏幕
- 分组标题宽度铺满
- 右侧索引栏高度根据字母数量自适应
- 搜索框水平方向自适应屏幕宽度

## 5. 无障碍支持

- 搜索框有明确的标签和提示
- 联系人项目使用语义化组件
- 点击区域足够大，便于触摸操作
- 提供清晰的视觉反馈

## 6. 性能优化

- 使用 AutomaticKeepAliveClientMixin 保持页面状态
- 使用 ListView.builder 实现列表项懒加载
- 使用 ValueKey 确保列表项正确重建
- 搜索结果使用高效的过滤算法
