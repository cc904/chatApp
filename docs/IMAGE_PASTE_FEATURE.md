# 聊天框图片粘贴功能使用指南

## 🎯 功能概述

聊天框图片粘贴功能允许用户直接在聊天输入框中粘贴图片，无需通过传统的文件选择器。该功能支持多平台，并针对不同平台特性提供了优化的用户体验。

## 📱 平台支持

### 桌面端 (macOS, Windows, Linux)
✅ **完整支持**
- 直接粘贴图片数据
- 粘贴图片文件
- 支持多种图片格式

### 移动端 (Android, iOS)
❌ **不支持**
- 移动端通过其他方式分享图片（相册选择、拍照等）
- 系统剪贴板API限制

## 🚀 使用方法

### 桌面端使用

1. **复制图片**
   - 右键点击网页图片 → "复制图像"
   - 从图片编辑软件复制
   - 复制图片文件

2. **粘贴图片**
   - 点击聊天输入框
   - 按 `Ctrl+V` (Windows/Linux) 或 `Cmd+V` (macOS)
   - 自动弹出图片预览对话框
   - 可添加文字说明
   - 点击发送

### 移动端使用

移动端不支持图片粘贴功能，请使用：
- 📷 拍照功能
- 📱 相册选择
- 📎 文件附件功能

## 📋 支持的图片格式

- **JPG/JPEG** - 常用照片格式
- **PNG** - 透明背景图片
- **GIF** - 动图支持
- **BMP** - 位图格式
- **WebP** - 现代网络格式
- **TIFF** - 高质量图片
- **ICO** - 图标文件
- **SVG** - 矢量图形

2. **ChatPage集成**

## 🛠 故障排除

### 常见问题

**Q: 桌面端粘贴没有反应？**
A: 确保图片已正确复制到剪贴板，可尝试重新复制。

**Q: 移动端提示"没有图片"？**
A: 移动端需要复制图片URL链接，不支持直接粘贴图片文件。

**Q: 图片下载失败？**
A: 检查网络连接，确保图片URL可访问。

**Q: 支持批量粘贴吗？**
A: 目前支持单张图片粘贴，批量功能在开发计划中。
