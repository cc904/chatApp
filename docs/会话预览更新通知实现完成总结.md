## 通知策略详解

### 策略1: 应用在后台 📱
- **触发条件**: `isAppInForeground = false`
- **通知方式**: 系统通知（通过 `MessageNotificationService`）
- **特点**: 
  - 支持动作按钮（回复、标记已读）
  - 支持通知分组
  - 支持声音和振动
  - 可在锁屏和通知栏显示

### 策略2: 应用在前台 + 会话列表页面 💬
- **触发条件**: `isAppInForeground = true` && `isChatsPageVisible = true`
- **通知方式**: 应用内横幅通知
- **特点**:
  - 显示在应用顶部的浮动横幅
  - 3秒自动消失
  - 可点击跳转到对应会话
  - 不影响当前操作

### 策略3: 应用在前台 + 其他页面 🔔
- **触发条件**: `isAppInForeground = true` && `isChatsPageVisible = false`
- **通知方式**: 轻量Toast + 角标更新
- **特点**:
  - 简短的Toast提示
  - 2秒自动消失
  - 更新应用角标数量
  - 最小化打扰

## 智能过滤机制

### 1. 自我消息过滤 🚫
```dart
// 检查是否是自己发送的消息（通过当前用户ID判断）
if (message.senderId == currentUser.userId) {
  // 跳过通知
}
```

### 2. 当前会话过滤 👀
```dart
// 如果用户正在查看这个会话，不需要额外通知
if (isChatPageVisible && currentChatConversationId == conversationId) {
  // 跳过通知
}
```

### 3. 时间窗口过滤 ⏰
```dart
// 超过5分钟的消息不通知
if (messageTime.difference(DateTime.now()).inMinutes > 5) {
  // 跳过通知
}
```

### 4. 重复通知过滤 🔄
- 内部维护已通知消息ID集合
- 避免同一消息多次通知

## 使用方法

### 自动使用 🚀
功能已自动集成到现有的消息处理流程中，无需额外配置：

1. 当 `ChatsRepositoryImpl` 收到 `conversation:preview:updated` 事件
2. 更新本地会话数据后自动调用通知处理
3. 系统根据当前应用状态选择合适的通知方式

### 手动测试 🧪
```dart
// 手动触发会话预览更新通知（用于测试）
await ConversationPreviewNotificationService.instance.handleConversationPreviewUpdated(
  previewUpdate: testPreviewUpdate,
  conversation: testConversation,
  sender: testSender,
  isAppInForeground: false, // 测试后台通知
  isChatsPageVisible: false,
  isChatPageVisible: false,
  currentChatConversationId: null,
);
```
