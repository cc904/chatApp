## 功能详细说明

### 通知设置选项

#### 基础设置
- **接收通知**: 总开关，控制是否接收任何通知
- **声音**: 控制通知声音播放
- **振动**: 控制通知振动
- **LED指示灯**: 控制LED通知灯（支持的设备）
- **显示消息预览**: 在通知中显示消息内容
- **分组消息**: 同一聊天的消息合并显示

#### 勿扰模式
- **勿扰时间**: 可设置免打扰时间段
- **开始时间**: 自定义勿扰开始时间
- **结束时间**: 自定义勿扰结束时间
- **跨午夜支持**: 支持22:00-08:00这样的跨天时间段

#### 通知类型控制
- **私聊消息**: 控制私人聊天通知
- **群聊消息**: 控制群组聊天通知
- **频道消息**: 控制频道消息通知

#### 高级功能
- **系统通知设置**: 引导用户打开系统设置
- **测试通知**: 发送测试通知验证功能
- **重新请求权限**: 重新申请通知权限

### ProfilePage 集成

#### 通知状态显示
- 在通知设置项目下显示当前状态：
  - "已开启" - 通知正常
  - "勿扰模式" - 当前在勿扰时间内
  - "已关闭" - 通知已被关闭

#### 快速操作
- **快速切换按钮**: 可以直接在 ProfilePage 快速开关通知
- **状态颜色指示**: 绿色表示正常，橙色表示有限制

## 技术实现

### 数据存储
使用 `SharedPreferences` 存储用户设置：
```dart
// 基础设置
'notifications_enabled' - 通知总开关
'notification_sound' - 声音开关
'notification_vibration' - 振动开关
'notification_led' - LED开关
'notification_preview' - 预览开关
'notification_group' - 分组开关

// 勿扰模式
'quiet_hours_enabled' - 勿扰模式开关
'quiet_start_hour/minute' - 开始时间
'quiet_end_hour/minute' - 结束时间

// 通知类型
'notify_private_chats' - 私聊通知
'notify_group_chats' - 群聊通知
'notify_channels' - 频道通知
```
