### 1. Proto 消息类型补充（✅ 完成）

在 `conversation.proto` 中新增了以下消息类型：

```protobuf
// 退出会话请求
message ConversationExitRequest {
  string conversation_id = 1;
  optional string reason = 2;
}

// 退出会话响应
message ConversationExitResponse {
  bool success = 1;
  string message = 2;
  string conversation_id = 3;
}

// 成员退出通知
message MemberExitedNotification {
  string conversation_id = 1;
  string user_id = 2;
  string user_name = 3;
  int64 exited_at = 4;
  string reason = 5;
}

// 会话移除通知
message ConversationRemovedNotification {
  string conversation_id = 1;
  string conversation_name = 2;
  int64 removed_at = 3;
  string reason = 4;
}
```

## 🔄 完整事件流程

### 用户主动退出会话流程

```
1. 用户点击"退出群聊"/"删除联系人"按钮
   ↓
2. ChatInfoPage 调用 ChatCubit.exitCurrentConversation()
   ↓
3. ChatCubit 调用 ChatRepository.exitConversation()
   ↓
4. ChatRepository 发送 Socket.io 事件: conversation:exit
   ↓
5. 服务器处理：
   - 从数据库移除用户
   - 发送响应: conversation:exit:response
   - 广播通知: conversation:member:exited (给其他成员)
   - 发送通知: conversation:removed (给退出的用户)
   ↓
6. 客户端处理：
   - 接收 conversation:exit:response → 删除本地会话数据
   - 其他成员接收 conversation:member:exited → 更新成员列表
   - 退出的用户接收 conversation:removed → 显示确认通知
```

### 管理员移除成员流程（已有功能）

```
1. 管理员点击"移除成员"按钮
   ↓
2. 发送: conversation:member:change (action: "remove")
   ↓
3. 服务器处理 + 广播: conversation:member:changed
   ↓ (新增)
4. 服务器发送: conversation:removed (给被移除的用户)
   ↓
5. 被移除用户接收通知，删除本地会话数据
```

## 🎯 关键特性

### 1. 区分退出类型
- **主动退出**：用户自己点击退出按钮（conversation:exit）
- **被动移除**：管理员移除成员（conversation:member:change）

### 2. 完整通知链
- **退出者**：收到 `conversation:removed` 通知，删除本地数据
- **其他成员**：收到 `conversation:member:exited` 通知，更新成员列表
- **退出响应**：`conversation:exit:response` 确认操作结果

### 3. 本地数据清理
- 自动删除会话记录
- 自动删除相关消息
- 显示用户友好的通知

### 4. 错误处理
- 网络异常处理
- 服务器响应验证
- 用户反馈机制
