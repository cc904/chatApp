## 实现内容

### 1. Protocol Buffers 接口定义

#### 新增Proto消息类型

**文件**: `lib/core/proto/source/user.proto`

```protobuf
// 搜索结果 - 会话信息
message SearchConversationResult {
  string conversation_id = 1;    // 会话ID
  string name = 2;               // 会话名称  
  string avatar = 3;             // 会话头像
  string type = 4;               // 会话类型 ("group" 或 "channel")
  int32 participant_count = 5;   // 参与者数量
  string description = 6;        // 会话描述
  bool is_joined = 7;            // 是否已加入
}

// 统一搜索请求
message UniversalSearchRequest {
  string query = 1;                    // 搜索关键字（用户ID/群聊ID/频道ID）
  repeated string search_types = 2;    // 搜索类型列表
  int32 limit = 3;                     // 结果数量限制
  int64 timestamp = 4;                 // 时间戳
}

// 统一搜索响应  
message UniversalSearchResponse {
  bool success = 1;                           // 操作是否成功
  string message = 2;                         // 响应消息
  repeated UserProto users = 3;               // 用户搜索结果
  repeated SearchConversationResult conversations = 4; // 会话搜索结果
  string query = 5;                           // 搜索关键字
  repeated string searched_types = 6;         // 搜索的类型
  int32 user_count = 7;                       // 用户结果数量
  int32 conversation_count = 8;               // 会话结果数量
  int64 timestamp = 9;                        // 时间戳
}
```

### 2. 统一搜索服务

**文件**: `lib/core/services/universal_search_service.dart`

#### 核心功能

- **单例模式**: 确保全局唯一的搜索服务实例
- **智能搜索**: 根据输入内容自动判断搜索类型
- **类型筛选**: 支持按用户、群聊、频道或全部类型搜索
- **结果限制**: 支持设置每种类型的最大结果数
- **错误处理**: 完善的异常处理和日志记录

#### 主要方法

1. **`search()`** - 执行统一搜索
2. **`searchUsers()`** - 专门搜索用户
3. **`searchGroups()`** - 专门搜索群聊
4. **`searchChannels()`** - 专门搜索频道
5. **`smartSearch()`** - 智能搜索（自动判断类型）

#### 智能搜索逻辑

```dart
// 纯数字：可能是ID，搜索所有类型
if (RegExp(r'^[0-9]+$').hasMatch(trimmedQuery)) {
  searchTypes = ['user', 'group', 'channel'];
}
// 包含@：优先搜索用户
else if (trimmedQuery.contains('@')) {
  searchTypes = ['user'];
}
// 包含"群"或"组"：优先搜索群聊
else if (trimmedQuery.contains(RegExp(r'[群组]'))) {
  searchTypes = ['group'];
}
// 包含"频道"：优先搜索频道
else if (trimmedQuery.contains(RegExp(r'频道|channel'))) {
  searchTypes = ['channel'];
}
```
