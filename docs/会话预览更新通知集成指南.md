# 会话预览更新通知集成指南

## 概述

本指南介绍如何在聊天应用中集成会话预览更新通知功能，当收到 `conversation:preview:updated` 事件时，根据应用状态智能选择合适的通知方式。

## 核心组件

### 1. ConversationPreviewNotificationService
- **位置**: `lib/core/services/conversation_preview_notification.dart`
- **功能**: 处理会话预览更新通知，提供多种通知策略
- **特性**:
  - 智能通知过滤（避免自己的消息、重复通知等）
  - 多种通知方式（系统通知、应用内通知、Toast、角标）
  - 应用状态感知（前台/后台、页面可见性）
  - 时间窗口控制（避免过旧消息通知）

### 2. UINotificationService (已扩展)
- **位置**: `lib/core/services/ui_notification_service.dart`
- **新增功能**:
  - `showTopBanner()`: 显示顶部横幅通知
  - `showToast()`: 显示Toast通知
  - `ToastType` 枚举: 定义通知类型

## 通知策略

### 1. 应用在后台
- **策略**: 显示系统通知
- **实现**: 使用现有的 `MessageNotificationService`
- **特点**: 支持动作按钮、分组、声音振动

### 2. 应用在前台 + 会话列表页面可见
- **策略**: 显示应用内横幅通知
- **实现**: 使用 `UINotificationService.showTopBanner()`
- **特点**: 3秒自动消失，可点击跳转到对应会话

### 3. 应用在前台 + 其他页面
- **策略**: 显示轻量Toast + 更新角标
- **实现**: 
  - `UINotificationService.showToast()`
  - `MessageNotificationService.setBadgeCount()`
- **特点**: 2秒自动消失，不打扰用户当前操作

## 智能过滤机制

### 1. 自己发送的消息
- 通过当前用户ID过滤，避免自己的消息产生通知

### 2. 正在查看的会话
- 如果用户正在查看消息所属的会话，不显示通知

### 3. 消息时间窗口
- 超过5分钟的消息不显示通知，避免过旧消息干扰

### 4. 重复通知
- 内部去重机制，同一消息不会重复通知

## 需要完善的功能

### 1. 导航状态检测

需要在项目中实现页面状态检测机制：

```dart
// 示例实现
class NavigationStateManager {
  static String? _currentRoute;
  static String? _currentChatConversationId;
  
  static bool get isChatsPageVisible => _currentRoute == '/chats';
  static bool get isChatPageVisible => _currentRoute?.startsWith('/chat/') ?? false;
  static String? get currentChatConversationId => _currentChatConversationId;
  
  static void updateRoute(String route) {
    _currentRoute = route;
    if (route.startsWith('/chat/')) {
      _currentChatConversationId = route.split('/').last;
    } else {
      _currentChatConversationId = null;
    }
  }
}
```

## 故障排除

### 常见问题

1. **通知不显示**
   - 检查应用状态检测逻辑
   - 验证过滤条件是否过于严格
   - 查看日志中的处理流程

2. **重复通知**
   - 检查事件监听是否重复注册
   - 验证消息去重逻辑

3. **通知内容不准确**
   - 检查发送者信息匹配逻辑
   - 验证会话信息同步状态
