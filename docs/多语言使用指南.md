# 多语言使用指南

## 概述

本项目使用Flutter的国际化支持实现多语言功能。目前支持中文(zh)和英文(en)两种语言。

## 技术实现

### 核心文件

- `lib/core/l10n/app_localizations.dart`: 本地化基类，定义了所有需要翻译的字符串
- `lib/core/l10n/app_localizations_zh.dart`: 中文翻译实现
- `lib/core/l10n/app_localizations_en.dart`: 英文翻译实现

### 依赖项

项目使用了以下Flutter国际化相关的依赖：

```yaml
dependencies:
  flutter_localizations:
    sdk: flutter
  intl: ^0.18.0
```

## 如何使用

### 1. 在Widget中访问本地化文本

在任何Widget中，都可以通过以下方式获取当前语言环境下的本地化文本：

```dart
// 获取本地化实例
final localizations = AppLocalizations.of(context);

// 使用本地化文本
Text(localizations.appName)
```

### 2. 格式化带参数的文本

对于需要插入变量的文本，可以使用本地化类中定义的格式化方法：

```dart
// 使用带参数的本地化方法
Text(localizations.cannotOpenChatWith(userName))

// 使用复数形式
Text(localizations.formatMinutesAgo(5)) // 输出 "5分钟前" 或 "5 minutes ago"
```

### 3. 添加新的翻译文本

如果需要添加新的翻译文本，请按照以下步骤操作：

1. 在 `app_localizations.dart` 中添加新的getter方法
2. 在 `app_localizations_zh.dart` 中实现中文翻译
3. 在 `app_localizations_en.dart` 中实现英文翻译

例如：

```dart
// 在 app_localizations.dart 中
String get newFeature;

// 在 app_localizations_zh.dart 中
@override
String get newFeature => '新功能';

// 在 app_localizations_en.dart 中
@override
String get newFeature => 'New Feature';
```

### 4. 添加新的语言支持

如果需要添加新的语言支持，请按照以下步骤操作：

1. 创建新的语言实现类，例如 `app_localizations_ja.dart` (日语)
2. 在 `app_localizations.dart` 的 `isSupported` 方法中添加新语言的代码
3. 在 `lookupAppLocalizations` 方法中添加新语言的分支
4. 在 `supportedLocales` 列表中添加新语言的Locale

## 最佳实践

1. **避免硬编码文本**：所有UI中显示的文本都应该使用本地化文本，避免直接在代码中硬编码文本字符串

2. **使用有意义的键名**：为翻译文本选择有意义的键名，便于理解和维护

3. **分类组织**：按功能或页面对翻译文本进行分类组织，提高可维护性

4. **保持翻译文件同步**：确保所有语言的翻译文件中都包含相同的键，避免缺失翻译

5. **测试不同语言**：在开发过程中定期测试不同语言环境下的UI表现

## 常见问题

### 如何切换应用语言？

项目中实现了语言切换功能，可以通过以下方式切换语言：

1. 进入个人资料页面
2. 点击"语言"选项
3. 选择所需语言
4. 重启应用以应用新的语言设置

### 文本没有正确翻译怎么办？

1. 检查是否已经在本地化文件中添加了对应的翻译
2. 确认使用了正确的键名
3. 确认应用正确初始化了本地化支持

### 如何处理动态内容的翻译？

对于包含动态内容的文本，可以使用带参数的方法，例如：

```dart
// 在 app_localizations.dart 中定义
String userJoinedGroup(String userName);

// 在实现类中提供翻译
@override
String userJoinedGroup(String userName) => '$userName 加入了群组';
```
