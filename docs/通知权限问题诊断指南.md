# 通知权限问题诊断指南

## 问题现象

日志显示：
```
[WARNING] 通知权限未授予，无法显示系统通知 : {
  conversationId: gzZkbHaWEF, 
  serviceStatus: {isInitialized: true, hasPermission: false}
}
```

## 问题分析

### 状态解读
- `isInitialized: true` ✅ - 通知服务已正确初始化
- `hasPermission: false` ❌ - 通知权限未获得

这表明问题出现在权限获取阶段，而不是服务初始化阶段。

## 可能的原因

### 1. 用户拒绝了权限请求
在应用首次启动时，用户点击了"拒绝"按钮

### 2. 权限被手动禁用
用户在系统设置中关闭了应用的通知权限

### 3. Android 13+ 权限政策
Android 13 (API 33) 及以上版本需要显式请求 `POST_NOTIFICATIONS` 权限

### 4. iOS 权限被拒绝
iOS 用户拒绝了通知权限请求

```dart
// 修改 ConversationPreviewNotificationService._showSystemNotification
Future<void> _showSystemNotification(
  conversation_proto.ConversationPreviewUpdated previewUpdate,
  Conversation conversation,
  User? sender,
) async {
  try {
    // 检查权限状态
    final hasPermission = await _notificationService.checkPermissionStatus();
    
    if (!hasPermission) {
      _logger.i('权限被拒绝，尝试重新请求', extra: {
        'conversationId': previewUpdate.conversationId,
      });
      
      // 尝试重新请求权限
      final granted = await _notificationService.requestPermissionAgain();
      
      if (!granted) {
        _logger.w('重新请求权限失败，显示用户引导');
        await _handlePermissionDenied(previewUpdate.conversationId);
        return;
      }
    }
    
    // 继续显示通知...
  } catch (error) {
    // 错误处理...
  }
}
```

### 方案3: 检查 AndroidManifest.xml 权限

确保在 `android/app/src/main/AndroidManifest.xml` 中有：

```xml
<!-- Android 13+ 需要的权限 -->
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.VIBRATE"/>

<!-- Android 12 及以下兼容 -->
<uses-permission android:name="android.permission.WAKE_LOCK"/>
```

### 方案4: 检查 iOS Info.plist 配置

确保在 `ios/Runner/Info.plist` 中有：

```xml
<key>UIBackgroundModes</key>
<array>
    <string>remote-notification</string>
    <string>background-processing</string>
</array>
```

## 常见问题解答

### Q: 为什么 Android 上权限请求失败？
**A:** Android 13+ 需要在运行时显式请求 `POST_NOTIFICATIONS` 权限。确保：
1. `AndroidManifest.xml` 中声明了权限
2. `flutter_local_notifications` 版本支持 Android 13+
3. 目标 SDK 版本正确

### Q: iOS 上权限总是被拒绝怎么办？
**A:** iOS 权限请求只能在应用首次启动时进行一次。如果被拒绝：
1. 用户必须在设置中手动开启
2. 应用可以检测权限状态并引导用户
3. 考虑在关键流程中提示权限重要性

### Q: 权限状态缓存问题？
**A:** 权限状态会被缓存在 `_hasPermission` 中。如果用户在设置中改变了权限：
1. 调用 `checkPermissionStatus()` 获取实时状态
2. 调用 `requestPermissionAgain()` 更新缓存状态
3. 重启应用会重新检查权限
