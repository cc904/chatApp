# 用户信息更新接口使用说明

## 概述

本文档介绍新添加的用户信息更新功能，使用 Protocol Buffers 和 Socket.io 实现前后端通信。

## 新增的 Proto 消息类型

### 1. SetCurrentUserRequest (设置当前用户信息请求)

```protobuf
message SetCurrentUserRequest {
  optional string name = 1;      // 用户名称（可选）
  optional string avatar = 2;    // 头像URL（可选）
  optional string phone = 3;     // 手机号（可选）
  optional string email = 4;     // 电子邮箱（可选）
  optional string status = 5;    // 状态信息（可选）
  int64 timestamp = 6;           // 时间戳
}
```

### 2. SetCurrentUserResponse (设置当前用户信息响应)

```protobuf
message SetCurrentUserResponse {
  bool success = 1;              // 操作是否成功
  string message = 2;            // 响应消息
  CurrentUserProto user = 3;     // 更新后的用户信息
  int64 timestamp = 4;           // 操作时间戳
}
```

### 3. CurrentUserUpdateEvent (当前用户信息更新事件)

```protobuf
message CurrentUserUpdateEvent {
  CurrentUserProto user = 1;            // 更新的用户信息
  repeated string updated_fields = 2;   // 更新的字段列表
  int64 timestamp = 3;                  // 更新时间戳
  string update_source = 4;             // 更新来源
}
```

## Socket.io 事件

### 客户端发送事件

- **`user:update`**: 发送用户信息更新请求
  - 参数: `SetCurrentUserRequest`
  - 描述: 客户端向服务器发送用户信息更新请求

### 服务器响应事件

- **`user:update:response`**: 用户信息更新响应
  - 参数: `SetCurrentUserResponse`
  - 描述: 服务器处理用户信息更新请求后的响应

### 服务器广播事件

- **`user:update:event`**: 用户信息更新事件
  - 参数: `CurrentUserUpdateEvent`
  - 描述: 当用户信息发生变化时广播给相关客户端

## 使用方法

### 1. 直接使用 UserService

```dart
import 'package:cc/core/services/user_service.dart';

// 获取 UserService 实例
final userService = UserService.instance;

// 更新用户信息
try {
  final response = await userService.updateCurrentUser(
    name: '新的用户名',
    avatar: 'https://example.com/avatar.jpg',
    status: '我的个性签名',
  );

  if (response != null && response.success) {
    print('用户信息更新成功: ${response.message}');
    print('更新后的用户ID: ${response.user.userId}');
  } else {
    print('用户信息更新失败: ${response?.message}');
  }
} catch (e) {
  print('更新用户信息时发生错误: $e');
}
```

### 2. 通过 ProfileRepository

```dart
import 'package:cc/features/profile/data/repositories/profile_repository.dart';

// 创建 ProfileRepository 实例

```

## 开发流程

### 1. 前端发起更新请求

```dart
// 1. 构建请求对象
final request = SetCurrentUserRequest()
  ..name = '新用户名'
  ..timestamp = Int64(DateTime.now().millisecondsSinceEpoch);

// 2. 发送请求
await communicationService.emitProto('user:update', request);

// 3. 等待响应
final response = await communicationService
    .onProto<SetCurrentUserResponse>('user:update:response')
    .timeout(const Duration(seconds: 10))
    .first;
```

### 2. 服务器处理逻辑

```javascript
// 服务器端处理逻辑（伪代码）
socket.on('user:update', async (data) => {
  try {
    // 1. 解析请求
    const request = SetCurrentUserRequest.decode(data);
    
    // 2. 验证权限
    if (socket.userId !== getCurrentUserId()) {
      throw new Error('无权限修改用户信息');
    }
    
    // 3. 更新数据库
    const updatedUser = await updateUserInDatabase(socket.userId, {
      name: request.name,
      avatar: request.avatar,
      status: request.status
    });
    
    // 4. 响应客户端
    const response = SetCurrentUserResponse.create({
      success: true,
      message: '用户信息更新成功',
      user: updatedUser,
      timestamp: Date.now()
    });
    socket.emit('user:update:response', response);
    
    // 5. 广播更新事件
    const event = CurrentUserUpdateEvent.create({
      user: updatedUser,
      updatedFields: ['name', 'avatar', 'status'],
      timestamp: Date.now(),
      updateSource: 'user_action'
    });
    socket.broadcast.emit('user:update:event', event);
    
  } catch (error) {
    const errorResponse = SetCurrentUserResponse.create({
      success: false,
      message: error.message,
      timestamp: Date.now()
    });
    socket.emit('user:update:response', errorResponse);
  }
});
```

## 注意事项

### 1. 网络状态检查
- 在发送请求前检查网络连接状态
- 实现适当的重试机制

### 2. 数据同步
- 服务器更新成功后同步更新本地数据库
- 监听服务器推送的更新事件以保持数据一致性

### 3. 用户体验
- 提供加载状态指示
- 实现适当的错误提示
- 支持离线编辑和在线同步

### 4. 安全考虑
- 验证用户权限
- 对敏感信息进行适当的验证和过滤
- 使用 HTTPS 加密传输
