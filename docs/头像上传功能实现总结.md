# 头像上传功能实现总结

## 问题描述

用户反馈头像上传功能存在以下问题：
1. 服务端返回404错误，说明 `/avatar` 接口还未实现
2. 头像上传成功后UI没有更新
3. 重启应用后头像信息丢失，没有持久化保存

## 解决方案

### 1. 服务端接口需求

已为服务端开发人员提供完整的接口需求文档：`docs/头像上传API接口需求.md`

**核心接口信息：**
- **方法**: `POST`
- **路径**: `/api/v1/upload/avatar`
- **Content-Type**: `multipart/form-data`
- **认证**: 需要 `Authorization: Bearer <token>` 头部
- **文件限制**: 最大10MB，支持 jpeg/png/gif/webp

### 2. 客户端架构实现

#### 2.1 上传服务层

```dart
Future<UploadApiResult> uploadAvatar(
  File avatarFile, {
  Function(int)? onProgress,

  return _uploadFile(
    file: avatarFile,
    type: 'avatar',

    onProgress: onProgress,

```

#### 2.2 业务逻辑层
**UserService** - `lib/core/services/user_service.dart`
```dart
/// 上传头像并更新用户信息
Future<SetCurrentUserResponse?> uploadAvatar(
  File avatarFile, {
  Function(int)? onProgress,
}) async {
  // 1. 上传头像文件到服务器
  final uploadResult = await _uploadApiService.uploadAvatar(
    avatarFile,
    onProgress: onProgress,
  );

  // 2. 更新用户信息（头像URL）
  final response = await updateCurrentUser(
    avatar: uploadResult.url!,
  );

  return response;
}
```

## 3. 数据流完整路径

### 头像上传流程
```
用户选择头像 → 
EditProfilePage._onSavePressed() → 
UserService.uploadAvatar() → 
  ├─ UploadApiService.uploadAvatar() (上传文件) 
  └─ UserService.updateCurrentUser() (更新用户信息) → 
ProfileCubit.updateUserInfo() → 
  ├─ ProfileRepository.updateUserInfo() 
  └─ UserService.updateCurrentUser() → 
    ├─ 服务器更新 
    └─ 本地数据库更新 → 
UI状态刷新 + 导航返回
```

### 数据持久化
1. **服务器端**：通过 `user:set` Socket.io 事件更新
2. **本地数据库**：通过 ProfileRepository.saveUser() 更新
3. **UI状态**：通过 ProfileCubit 状态管理更新

## 4. 修复的关键问题

### 问题1：UI不更新
**原因**：头像上传成功后直接返回，没有通过 ProfileCubit 更新状态
**修复**：调用 `profileCubit.updateUserInfo()` 刷新UI状态

### 问题2：数据不持久化
**原因**：
1. UserService 的 `_onUserInfoUpdated` 方法只记录日志，没有更新本地数据库
2. ProfileRepository 的更新逻辑通过 ProfileCubit 触发，确保数据同步

**修复**：
- 通过 ProfileCubit.updateUserInfo() 确保本地数据库更新
- ProfileRepository.updateUserInfo() 会调用 UserService 更新服务器，然后保存到本地

## 6. 服务端开发指南

### 必需实现的功能
1. **文件上传处理**：接收 multipart/form-data 格式的头像文件
2. **文件验证**：检查文件类型、大小、安全性
3. **存储管理**：上传到云存储（推荐OSS/S3）
4. **URL返回**：返回可公开访问的头像URL
5. **认证验证**：验证JWT token有效性

### 推荐的响应格式
```json
{

      "originalName": "avatar.jpg",
      "size": 245760,
      "mimeType": "image/jpeg",
      "width": 400,
      "height": 400
    }
  }
}
```
