# 服务器切换功能修复总结

## 问题描述

用户反馈服务器切换功能无法正常工作，切换服务器后应用仍然使用旧的服务器地址。

## 问题根因分析

经过分析发现了以下几个问题：

### 1. AppConfig 缺少持久化存储
- **问题**：`AppConfig` 类只在内存中保存服务器索引，应用重启后会重置为默认值
- **影响**：用户切换服务器后，重启应用会丢失设置

### 2. 单例模式的服务器URL更新问题
- **问题**：`AuthRepositoryImpl` 使用单例模式，但一旦创建实例后，后续调用会忽略新的 `serverUrl` 参数
- **影响**：切换服务器后，认证服务仍然使用旧的服务器地址

### 3. 相关服务的 baseUrl 没有同步更新
- **问题**：`EnhancedApiService` 和 `EnhancedTokenManager` 的 baseUrl 没有在服务器切换时更新
- **影响**：API 请求和 Token 刷新仍然指向旧服务器

## 修复方案

### 1. AppConfig 持久化存储

#### 修改内容
- 添加 `SharedPreferences` 依赖用于持久化存储
- 实现 `_loadServerIndex()` 和 `_saveServerIndex()` 方法
- 将所有服务器设置方法改为异步方法
- 添加 `init()` 方法确保配置正确初始化

#### 代码变更
```dart
// 添加持久化存储
Future<void> _loadServerIndex() async {
  final prefs = await SharedPreferences.getInstance();
  final savedIndex = prefs.getInt(_serverIndexKey);
  if (savedIndex != null && savedIndex >= 0 && savedIndex < serverUrls.length) {
    _currentServerIndex = savedIndex;
  }
}

Future<void> _saveServerIndex() async {
  final prefs = await SharedPreferences.getInstance();
  await prefs.setInt(_serverIndexKey, _currentServerIndex);
}
```

### 2. AuthRepositoryImpl 单例模式修复

#### 修改内容
- 修改 `getInstance()` 方法，检测服务器URL变化时重新创建实例
- 添加静态变量 `_currentServerUrl` 跟踪当前服务器URL
- 重置初始化状态确保新实例正确初始化

#### 代码变更
```dart
static AuthRepositoryImpl getInstance({required String serverUrl}) {
  // 如果服务器URL发生变化，重新创建实例
  if (_instance == null || _currentServerUrl != serverUrl) {
    _instance = AuthRepositoryImpl(serverUrl: serverUrl);
    _currentServerUrl = serverUrl;
    // 重置初始化状态，确保新实例会重新初始化
    _instance!._isInitialized = false;
  }
  return _instance!;
}
```

### 3. 相关服务的 baseUrl 同步更新

#### EnhancedTokenManager 修复
- 添加 `updateBaseUrl()` 方法允许动态更新内部 Dio 实例的 baseUrl

```dart
void updateBaseUrl(String baseUrl) {
  _dio.options.baseUrl = baseUrl;
  _logger.i('🔗 更新TokenManager基础URL', extra: {'baseUrl': baseUrl});
}
```

#### AuthRepositoryImpl 初始化修复
- 在 `init()` 方法中同时更新 `EnhancedApiService` 和 `EnhancedTokenManager` 的 baseUrl

```dart
// 设置API基础URL
_apiService.setBaseUrl(_serverUrl);

// 更新TokenManager的基础URL
_tokenManager.updateBaseUrl(_serverUrl);
```

### 4. main.dart 初始化修复

#### 修改内容
- 在应用启动时调用 `AppConfig.init()` 确保配置正确加载
- 移除旧的服务器URL存储逻辑，统一使用 `AppConfig` 的 `SharedPreferences` 存储

```dart
// 初始化全局配置
final appConfig = AppConfig();
await appConfig.init(); // 等待配置初始化完成
```

### 5. AuthPage 服务器切换逻辑优化

#### 修改内容
- 修改 `_switchServer()` 方法为异步方法，添加错误处理
- 确保服务器索引正确保存到持久化存储

```dart
void _switchServer(int serverIndex) async {
  try {
    // 保存服务器索引到持久化存储
    await _appConfig.setServerIndex(serverIndex);
    
    setState(() {
      // 关闭旧的AuthCubit实例
      if (!_authCubit.isClosed) {
        _authCubit.close();
      }
      // 重新创建AuthCubit实例以使用新的服务器URL
      _authCubit = AuthCubit(serverUrl: _appConfig.serverUrl);
    });

    // 显示成功消息和日志
    final localizations = AppLocalizations.of(context);
    UINotificationHelper.showSuccess('已切换到${_appConfig.currentServerName}');
    
    _logger.i('🔄 服务器切换成功', extra: {
      'serverIndex': serverIndex,
      'serverUrl': _appConfig.serverUrl,
      'serverName': _appConfig.currentServerName,
    });
  } catch (e) {
    _logger.e('服务器切换失败', error: e);
    UINotificationHelper.showError('服务器切换失败: ${e.toString()}');
  }
}
```
