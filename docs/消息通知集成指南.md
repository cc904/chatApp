# 消息通知集成指南

## 概述

本指南介绍如何在聊天应用中集成消息通知功能，使用 `flutter_local_notifications` 插件实现本地通知。

## 核心组件

### 1. MessageNotificationService
- **位置**: `lib/core/services/message_notification_service.dart`
- **功能**: 核心通知服务，处理通知的显示、权限、渠道管理
- **特性**:
  - 支持Android/iOS/macOS多平台
  - 自动权限管理
  - 通知分组（按会话）
  - 动作按钮（回复、标记已读）
  - 富媒体通知样式

### 2. ChatNotificationIntegration
- **位置**: `lib/core/services/chat_notification_integration.dart`
- **功能**: 聊天通知集成逻辑，处理应用状态和通知触发
- **特性**:
  - 智能通知过滤
  - 去重处理
  - 应用状态检测
  - 未读计数管理

## 集成步骤

### Step 1: 权限配置

#### Android权限 (已配置)
```xml
<!-- AndroidManifest.xml -->
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.VIBRATE"/>
```

#### iOS权限 (已配置)
```xml
<!-- Info.plist -->
<key>UIBackgroundModes</key>
<array>
    <string>remote-notification</string>
    <string>background-processing</string>
</array>
```

### Step 2: 初始化服务

在 `main.dart` 中已添加初始化代码：
```dart
// 🔔 初始化消息通知服务
logger.i('初始化消息通知服务');
await MessageNotificationService.instance.initialize();
```

### Step 3: 集成到消息接收流程

在你的消息接收逻辑中添加通知处理：

```dart
// 示例：在Socket.io消息处理中
void _handleNewMessage(MessageProto messageProto) async {
  // 1. 保存消息到数据库
  final message = await _saveMessageToDatabase(messageProto);
  
  // 2. 获取会话和发送者信息
  final conversation = await _getConversation(message.conversationId);
  final sender = await _getUser(message.senderId);
  
  // 3. 检查应用状态
  final isAppInForeground = WidgetsBinding.instance.lifecycleState == AppLifecycleState.resumed;
  final isChatPageVisible = _isCurrentChatPage(conversation.conversationId);
  
  // 4. 显示通知
  await ChatNotificationIntegration.instance.handleNewMessage(
    message: message,
    conversation: conversation,
    sender: sender,
    isAppInForeground: isAppInForeground,
    isChatPageVisible: isChatPageVisible,
    unreadCount: conversation.unreadCount,
  );
}
```

### Step 4: 用户状态管理

在应用启动时设置当前用户：
```dart
// HomePage或AuthPage中
final currentUser = await _getCurrentUser();
ChatNotificationIntegration.instance.setCurrentUserId(currentUser.userId);
```

### Step 5: 聊天页面集成

在聊天页面中清除通知：
```dart
class ChatPage extends StatefulWidget {
  @override
  void initState() {
    super.initState();
    // 进入聊天页面时清除该会话的通知
    ChatNotificationIntegration.instance.onChatPageEntered(widget.conversationId);
  }
}
```

### Step 6: 应用生命周期处理

在应用生命周期变化时更新状态：
```dart
class AppLifecycleHandler with WidgetsBindingObserver {
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.paused:
        ChatNotificationIntegration.instance.onAppBackground();
        break;
      case AppLifecycleState.resumed:
        ChatNotificationIntegration.instance.onAppForeground();
        break;
    }
  }
}
```

## 核心功能说明

### 1. 智能通知过滤
- ✅ 过滤自己发送的消息
- ✅ 避免重复通知同一消息
- ✅ 应用在前台且聊天页面可见时不通知
- ✅ 过滤过旧的消息（超过5分钟）

### 2. 通知样式
- **单条消息**: BigTextStyle显示完整内容
- **多条消息**: InboxStyle显示消息列表
- **分组通知**: 按会话分组，避免通知栏混乱

### 3. 动作按钮
- **标记已读**: 快速标记会话为已读状态
- **回复**: 直接在通知中输入回复内容

### 4. 跨平台支持
- **Android**: 完整功能支持，包括渠道、分组、动作
- **iOS**: 基础通知、角标、声音
- **macOS**: 桌面通知支持

## 注意事项

### 1. 权限处理
- Android 13+需要显式请求通知权限
- iOS需要用户主动授权
- 应提供权限设置页面引导

### 2. 性能优化
- 通知服务已优化，避免频繁初始化
- 使用去重机制避免重复通知
- 合理设置通知时间窗口

### 3. 用户体验
- 通知内容要清晰易懂
- 支持通知分组，避免打扰
- 提供通知设置选项

## 故障排除

### 常见问题

1. **通知不显示**
   - 检查权限是否授予
   - 验证应用状态判断逻辑
   - 查看日志中的过滤原因

2. **重复通知**
   - 检查消息去重逻辑
   - 验证消息ID的唯一性

3. **通知样式异常**
   - 检查图标和资源文件
   - 验证Android渠道配置

4. **iOS通知不工作**
   - 检查Info.plist配置
   - 验证权限请求流程

### 调试技巧

1. 启用详细日志：
