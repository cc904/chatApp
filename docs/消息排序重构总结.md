# 消息排序重构总结

## 背景
用户要求将所有分散的消息排序逻辑提取为一个独立的排序函数，以提高代码的可维护性和一致性。

## 重构目标
1. **统一排序逻辑**：将所有消息排序代码集中到一个工具类中
2. **处理特殊需求**：正确处理临时消息（messageIndex = 0）的排序
3. **提高代码复用**：避免重复的排序代码
4. **保持性能**：结合数据库排序和内存排序的优势

## 实现方案

### 1. 创建 MessageSortUtils 工具类

**文件位置**: `lib/core/utils/message_sort_utils.dart`

**主要功能**:
- `compareForDisplay()`: 聊天界面显示排序比较器
- `compareForHistory()`: 历史消息加载排序比较器
- `sortForDisplay()`: 显示排序便捷方法
- `sortForHistory()`: 历史排序便捷方法
- `getSortedForDisplay()`: 获取排序后的新列表（显示）
- `getSortedForHistory()`: 获取排序后的新列表（历史）
- `validateDisplaySort()`: 排序验证工具

### 2. 排序规则设计

#### 显示排序（compareForDisplay）
1. **临时消息优先**：messageIndex = 0 的消息排在最前面
2. **时间排序**：临时消息之间按创建时间降序排列（最新的在前）
3. **正常排序**：非临时消息按 messageIndex 降序排列
4. **辅助排序**：相同 messageIndex 时按创建时间降序排列

#### 历史排序（compareForHistory）
1. **正常消息优先**：按 messageIndex 升序排列
2. **临时消息最后**：messageIndex = 0 的消息排在最后
3. **时间排序**：临时消息之间按创建时间升序排列

### 3. 二阶段排序策略

#### 为什么需要二阶段排序？
由于数据库不理解我们的特殊排序规则（临时消息 messageIndex = 0 优先），采用以下策略：

#### 第一阶段：数据库排序
```dart
// 在数据库查询时，先按 messageIndex 降序排序
final messages = await queryBuilder
  .sortByMessageIndexDesc()  // 数据库层面排序
  .findAll();
```

#### 第二阶段：内存排序
```dart
// 查询完成后，在内存中使用我们的排序规则重新排序
MessageSortUtils.sortForDisplay(messages);
```

#### 优势
- **数据库排序**：确保大部分正常消息已经是正确顺序，提高查询效率
- **内存排序**：处理临时消息（messageIndex = 0）的特殊位置需求
- **性能优化**：避免数据库返回完全无序的数据，减少内存排序负担

## 重构执行

### 1. 移除旧的排序方法
从 `Message` 类中移除：
- `compareForDisplay()` 静态方法
- `compareForHistory()` 静态方法

### 2. 替换所有排序调用

#### ChatCubit 中的替换
- `mergedList.sort((a, b) => b.messageIndex.compareTo(a.messageIndex))` 
  → `MessageSortUtils.sortForDisplay(mergedList)`
- `messagesFromDb.sort((a, b) => b.messageIndex.compareTo(a.messageIndex))` 
  → `MessageSortUtils.sortForDisplay(messagesFromDb)`
- `Message.compareForDisplay` → `MessageSortUtils.compareForDisplay`

#### ChatRepositoryImpl 中的添加
在所有关键数据库查询后添加内存排序：
- 初始消息加载 (INITIAL)
- 向前加载更多 (LOAD_MORE_BEFORE) 
- 向后加载更多 (LOAD_MORE_AFTER) - 使用历史排序
- 消息搜索
- 指定范围消息加载

#### ChatsRepositoryImpl 中的添加
为特定类型消息查询添加排序：
- 媒体消息 (getMediaMessages)
- 文件消息 (getFileMessages)
- 语音消息 (getVoiceMessages)
- 链接消息 (getLinkMessages)

#### 其他文件
- `ChatSearchPage`: 搜索结果排序
- `DebugCommands`: 测试排序功能

### 3. 更新导入和清理代码
