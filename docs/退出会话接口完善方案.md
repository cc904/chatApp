# 退出会话接口完善方案

## 📋 现状分析

### ✅ 已实现的功能
1. **临时离开会话房间**：
   - `conversation:leave` - 离开会话房间请求（不从数据库移除）
   - `conversation:leave:response` - 离开会话房间响应

2. **管理员移除成员**：
   - `conversation:member:change` - 会话成员管理（action: "remove"）
   - `conversation:member:changed` - 成员变更广播通知

3. **用户离开通知**：
   - `conversation:user:left` - 用户离开会话通知

### ❌ 缺失的功能
1. **用户主动退出会话**（真正退出，从数据库移除）
2. **成员退出通知**（区别于被移除）
3. **会话移除通知**（通知被退出的用户）

## 🎯 完善方案

### 1. Proto消息类型补充

需要在 `conversation.proto` 中补充以下消息类型：

```protobuf
// ================================
// 退出会话管理 (Exit Management)
// ================================

// 退出会话请求
// Socket.io事件: conversation:exit
message ConversationExitRequest {
  // 会话ID
  string conversation_id = 1;
  // 退出原因（可选）
  optional string reason = 2;
}

// 退出会话响应
// Socket.io事件: conversation:exit:response
message ConversationExitResponse {
  // 是否成功
  bool success = 1;
  // 提示消息
  string message = 2;
  // 会话ID
  string conversation_id = 3;
}

// 成员退出通知（用于广播给其他成员）
// Socket.io事件: conversation:member:exited
message MemberExitedNotification {
  // 会话ID
  string conversation_id = 1;
  // 退出的用户ID
  string user_id = 2;
  // 退出的用户名称
  string user_name = 3;
  // 退出时间
  int64 exited_at = 4;
  // 退出原因
  string reason = 5;
}

// 会话移除通知（发送给被退出的用户自己）
// Socket.io事件: conversation:removed
message ConversationRemovedNotification {
  // 会话ID
  string conversation_id = 1;
  // 会话名称
  string conversation_name = 2;
  // 移除时间
  int64 removed_at = 3;
  // 移除原因
  string reason = 4;
}
```

#### 3.2 ChatRepositoryImpl实现

```dart
class ChatRepositoryImpl implements ChatRepository {
  // ... 现有实现

  /// 退出会话（真正退出，从数据库移除）
  @override
  Future<bool> exitConversation(String conversationId, {String? reason}) async {
    try {
      _logger.i('用户主动退出会话', extra: {
        'conversationId': conversationId,
        'reason': reason,
      });

      if (_communicationService.isInitialized) {
        final exitRequest = conversation_proto.ConversationExitRequest()
          ..conversationId = conversationId;
        
        if (reason != null) {
          exitRequest.reason = reason;
        }

        final success = await _communicationService.emitProto(
          'conversation:exit', 
          exitRequest
        );

        if (success) {
          _logger.i('退出会话请求已发送', extra: {
            'conversationId': conversationId,
          });
          return true;
        } else {
          _logger.w('发送退出会话请求失败');
          return false;
        }
      } else {
        _logger.w('通信服务未初始化，无法发送退出会话请求');
        return false;
      }
    } catch (error) {
      _logger.e('退出会话失败', error: error);
      return false;
    }
  }

  // 新增事件处理方法
  void _handleConversationExitResponse(
      conversation_proto.ConversationExitResponse response) async {
    try {
      _logger.i('收到退出会话响应', extra: {
        'conversationId': response.conversationId,
        'success': response.success,
        'message': response.message,
      });

      if (response.success) {
        // 从本地数据库中删除该会话
        await _deleteConversationLocally(response.conversationId);
        _logger.i('本地会话已删除', extra: {
          'conversationId': response.conversationId,
        });
      }
    } catch (error, stackTrace) {
      _logger.e('处理退出会话响应失败', error: error, stackTrace: stackTrace);
    }
  }

  void _handleMemberExitedNotification(
      conversation_proto.MemberExitedNotification notification) async {
    try {
      _logger.i('收到成员退出通知', extra: {
        'conversationId': notification.conversationId,
        'userId': notification.userId,
        'userName': notification.userName,
        'reason': notification.reason,
      });

      // 更新本地会话的参与者列表
      await _updateConversationParticipants(
        notification.conversationId,
        removeUserId: notification.userId,
      );
    } catch (error, stackTrace) {
      _logger.e('处理成员退出通知失败', error: error, stackTrace: stackTrace);
    }
  }

  void _handleConversationRemovedNotification(
      conversation_proto.ConversationRemovedNotification notification) async {
    try {
      _logger.i('收到会话移除通知', extra: {
        'conversationId': notification.conversationId,
        'conversationName': notification.conversationName,
        'reason': notification.reason,
      });

      // 从本地数据库中删除该会话
      await _deleteConversationLocally(notification.conversationId);
      
      // 显示通知给用户
      UINotificationService().showInfo(
        '您已${notification.reason == "exit" ? "退出" : "被移除"}会话：${notification.conversationName}'
      );
    } catch (error, stackTrace) {
      _logger.e('处理会话移除通知失败', error: error, stackTrace: stackTrace);
    }
  }

  /// 从本地数据库删除会话
  Future<void> _deleteConversationLocally(String conversationId) async {
    await _isar.writeTxn(() async {
      // 删除会话记录
      await _conversations
          .filter()
          .conversationIdEqualTo(conversationId)
          .deleteAll();
      
      // 删除相关消息
      await _messages
          .filter()
          .conversationIdEqualTo(conversationId)
          .deleteAll();
    });
  }
}
```

## 🔄 事件流程图

### 用户主动退出会话流程

```
1. 用户点击"退出群聊"按钮
   ↓
2. 客户端发送: conversation:exit
   ↓
3. 服务器处理：
   - 从数据库移除用户
   - 发送响应: conversation:exit:response
   - 广播通知: conversation:member:exited (给其他成员)
   - 发送通知: conversation:removed (给退出的用户)
   ↓
4. 客户端处理：
   - 接收响应，删除本地会话数据
   - 其他成员接收退出通知，更新成员列表
   - 退出的用户接收移除通知，显示确认信息
```

### 管理员移除成员流程

```
1. 管理员点击"移除成员"按钮
   ↓
2. 客户端发送: conversation:member:change (action: "remove")
   ↓
3. 服务器处理：
   - 从数据库移除目标用户
   - 广播通知: conversation:member:changed (给所有成员)
   - 发送通知: conversation:removed (给被移除的用户)
   ↓
4. 客户端处理：
   - 所有成员接收变更通知，更新成员列表
   - 被移除的用户接收移除通知，删除本地会话数据
```

3. ❌ 会话移除通知（给被退出的用户）
4. ❌ 相关的Proto消息类型定义
5. ❌ 客户端事件处理逻辑
